# 2. Stakeholders and RACI

| Stakeholder | What they need | RACI |
| --- | --- | --- |
| Hospital COO (sponsor) | Faster discharges, more bed availability, fewer complaints | Accountable |
| Business Analyst | Requirements, analysis, documents, UAT support | Responsible |
| Insurance / TPA desk manager | Complete files, a live view of every claim's clock | Responsible |
| Billing team | Itemised bill and pharmacy / implant invoices ready on time | Responsible |
| Medical Superintendent and doctors | Simple discharge planning that does not slow ward rounds | Consulted |
| Medical records team | Discharge summary completed before the file is sent | Consulted |
| Nursing / ward in-charge | Clear discharge time so the bed can be prepared | Consulted |
| IT / HIS team | Feasible changes to the hospital information system | Responsible |
| Insurers and TPAs (external) | Complete, correct documents in one go | Consulted |
| Patients and families | A predictable discharge time and no surprise bills | Informed |

## Elicitation plan

| Technique | With whom | Purpose |
| --- | --- | --- |
| Interviews | COO, desk manager, billing head | Goals, constraints, success measures |
| Observation (job shadowing) | Insurance desk and billing on a busy afternoon | How a discharge file is really built |
| Workshop | Doctors, nursing, medical records | Morning discharge planning that works for the wards |
| Document analysis | Claim data, insurer query reasons, IRDAI circular | Where time is lost and why |
| Patient feedback survey | Discharged patients | Pain points in their own words |

> In this case study the stakeholders and interviews are simulated; the data analysis is real analysis of synthetic data.
