# Data dictionary

All files are **synthetic** (generated by [`scripts/generate_data.py`](../scripts/generate_data.py)). Narmada Hospitals, its patients and insurers are fictional; payers are shown only by type. Admissions: 1 January to 30 June 2026.

## claims_raw.csv (12,180 rows) and claims_clean.csv (12,000 rows)

One row per cashless admission. The raw file has deliberate issues for the cleaning step:

| Issue | Rows |
| --- | --- |
| Exact duplicate rows | 180 |
| `payer_type` in wrong case or with a leading space | 500 |
| Short department names (Ortho, Cardio, Surgery, Gen Medicine, OBG, Onco) | 300 |

| Column | Meaning |
| --- | --- |
| claim_id | Unique ID (CL00001 ...) |
| hospital | Nagpur / Pune / Nashik |
| department | Cardiology, Orthopaedics, General Surgery, General Medicine, Maternity, Oncology |
| admission_type | Planned / Emergency |
| payer_type | Standalone Health Insurer / Private General Insurer / PSU General Insurer |
| via_tpa | Yes if the claim is handled by a Third Party Administrator |
| policy_type | Retail (individual / family) / Group (employer) |
| room_category | General Ward / Twin Sharing / Single Room |
| admitted_at | Admission date and time |
| preauth_requested_at / preauth_decided_at | Pre-authorisation request sent / insurer decision |
| preauth_outcome | Approved / Denied |
| preauth_queries | Number of insurer queries at pre-authorisation (0-2) |
| discharge_ordered_at | Doctor signs the discharge order |
| discharge_file_sent_at | Hospital sends final bill and papers to the insurer |
| final_approval_at | Insurer approves the final amount |
| patient_left_at | Patient leaves the hospital |
| discharge_queries | Insurer queries at final approval (0-1) |
| billed_amount / deduction_amount / approved_amount | Rupees; deduction = what the insurer does not pay |
| deduction_reason | Non-payable items / Room rent capping + non-payable items |
| claim_status | Settled cashless / Converted to reimbursement (pre-auth denied) |

Discharge columns and amounts are blank for denied claims.

## insurer_queries.csv (6,581 rows)

| Column | Meaning |
| --- | --- |
| query_id | Unique ID |
| claim_id | Links to claims.claim_id |
| query_stage | Pre-authorisation / Final discharge |
| query_reason | What the insurer asked for |
| raised_at / answered_at | When the insurer raised it / when the hospital answered |

## Rules used to generate the data

- The hospital insurance desk works 08:00-22:00; a patient whose payment finishes after 22:00 leaves at 09:30 next morning.
- Insurers that work through a TPA, and PSU insurers, take longer to approve.
- Emergency admissions get more pre-auth queries; a missing discharge summary raises the chance of a discharge query.
- Room-rent capping applies to some retail-policy patients in single rooms.
